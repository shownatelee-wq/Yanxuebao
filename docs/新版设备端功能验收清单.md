# 新版设备端功能验收清单

## 1. 验收范围

- [ ] 验收对象为新版 AI Agent 手表设备端 `apps/device-agent-shell`。
- [ ] 新版只做完整可交互前端演示，全部使用本地 mock 数据。
- [ ] 不开发后端，不新增 API 路由，不请求远程接口。
- [ ] 旧版设备端 `apps/device-shell` 不做代码修改。
- [ ] 新版和旧版可并行运行，便于业务方逐项对比。

## 2. 隔离开发验收

- [ ] 当前分支为 `codex/device-agent-v2`。
- [ ] 变更文件不包含 `apps/device-shell/**`。
- [ ] 新版应用目录为 `apps/device-agent-shell`。
- [ ] 根脚本包含 `pnpm dev:device-agent`，默认端口为 `3110`。
- [ ] 旧版仍使用 `pnpm dev:device`，默认端口为 `3105`。
- [ ] `test-results/` 等无关输出不纳入新版开发范围。

## 3. 纯前端 Mock 边界

- [ ] 新版源码中不存在 `fetch(`、`axios`、`XMLHttpRequest`。
- [ ] 新版源码中不存在 `/api/` 业务请求入口。
- [ ] 支付、SOS、AI 问答、AI 创作、AI 识物均为本地预置内容或前端状态。
- [ ] 付款码只展示 `YXB-PAY-260323` 模拟码，不产生真实支付。
- [ ] SOS 只模拟确认态、发送态、通知路由，不外呼、不发短信、不上报真实位置。
- [ ] 后续真实接口联调需另行输出接口 PRD 或技术方案。

## 4. 登录与账号验收

- [ ] 设备初始化支持租赁模式、销售模式、扫码授权三种方式。
- [ ] 租赁模式支持 6 位体验授权码校验，演示码为 `260323`。
- [ ] 授权码错误时有明确错误提示。
- [ ] 扫码授权有二维码或扫码状态演示，并可模拟授权成功。
- [ ] 初始化完成后进入学员登录方式选择。
- [ ] 学员登录支持账号登录与人脸登录。
- [ ] 账号登录支持演示账号选择、手机号输入、密码输入和错误提示。
- [ ] 演示密码为 `123456`。
- [ ] 人脸登录支持准备、扫描、成功三个状态。
- [ ] 添加账号意图在登录选择中有对应状态表达。

## 5. 四屏主结构验收

- [ ] 主屏为 AI 智能体成长伙伴，默认展示当前研学任务。
- [ ] 通知中心展示任务、广播、团队、家庭等通知。
- [ ] 成长中心展示成长值、能力指数、成长记录和测试入口。
- [ ] 应用中心完整展示 21 个应用入口。
- [ ] 设备支持左右滑切换四屏。
- [ ] 底部语音 Dock 展示最近操作反馈。
- [ ] 顶部状态栏展示时间、通知、电量等设备状态。

## 6. Agent 主线验收

- [ ] 主线活动为“小小生态公园设计师”。
- [ ] 主屏点击“主线”后进入独立 AI Agent 主线对话页，不在主屏内直接执行任务卡。
- [ ] 主线对话页保留状态栏、返回主屏按钮、当前阶段、进度和成长值。
- [ ] 主线由按钮逐步推进，不自动连续刷完 mock 内容。
- [ ] 主线包含 22 个 mock 节点，覆盖研学前准备、任务一、任务二、任务三、活动总结、成长奖励、研学日记保存。
- [ ] 任务二展示 10 个锦囊、当前线索、设施照片记录和锦囊完成进度。
- [ ] 任务三展示目标物种、设施名称、预期作用、AI 设计图和方案说明。
- [ ] 完成成长奖励后，本地成长值和任务进度可变化。
- [ ] 生成研学日记后展示素材清单、生成进度和保存结果。
- [ ] 主屏的任务卡、卡包、斗卡、能力、天赋、兴趣、画像、日记均为独立 Agent 页入口，不在主屏内嵌执行卡。
- [ ] 任务卡 Agent 按原型图覆盖 Step 1/6 到 Step 6/6：选择观察对象、选择反馈、拍照提交、AI 校验通过/驳回重拍、语音描述、语音转文字、关键信息确认、关系问答、AI 小助手总结、综合结算和成长值 +50。
- [ ] 卡包 Agent 覆盖任务筛选、待补充、我的卡包、卡片统计和生态探索系列 3/5。
- [ ] 斗卡 Agent 按 4.3 原型覆盖邀请、规则、6 道逐题答题、单题结果、完成结算和排行榜：开始斗卡后先出现 Step 1 题目，不提前展示得分；Step 2-6 需要先完成模拟填充/录音/输入，再出现提交按钮；每题答完后只展示当前题结果；顶部比分按 0/0、10/9、22/24、38/42、56/58、74/72、92/88 逐步推进；完成 6 题后才展示你赢了、92 vs 88、+50 成长值、五项分项对比和排行榜摘要；排行榜页展示第 2 名和 8 人排行榜。
- [ ] 能力 Agent 必须按“题目 -> 选择答案 -> 填充我的回答 -> 提交本题 -> 下一题/结果”的顺序推进，提交前不得展示能力雷达或成长建议。
- [ ] 天赋 Agent 必须按“情境题 -> 选择方向 -> 填充我的回答 -> 提交 -> 行为偏好整理 -> 提交 -> 潜力结果”的顺序推进，提交前不得展示潜力方向或推荐智能体。
- [ ] 兴趣 Agent 必须按“选择标签 -> 填充我的兴趣 -> 提交 -> 推荐依据确认/忽略 -> 提交 -> 兴趣结果”的顺序推进，标签不得在未选择/确认前提前写入结果。
- [ ] 能力、天赋、兴趣 Agent 完成后可更新成长画像完成度；兴趣第一步不展示“稍后再说”，推荐确认阶段的“稍后再说”和“忽略推荐”只保留当前状态，不计入对应标签确认。
- [ ] 画像 Agent 展示能力、天赋、兴趣和任务表现聚合结果。
- [ ] 日记 Agent 可聚合任务、照片、语音、评价、研学报告和成长值，并保存日记。

## 7. 应用中心验收

以下 21 个应用均需满足：有入口、有详情、有“进入应用”、有完整应用内页面、有可点击操作、有本地结果、有最近操作记录、有 Agent 提醒。

- [ ] 任务：任务卡、执行工作台、结算、卡包、斗卡。
- [ ] 拍拍：拍照、预览、重拍、保存、转发任务或日记。
- [ ] 问问：语音提问、多轮追问、保存答案。
- [ ] 闪记：语音闪记、视频闪记、转写、整理素材。
- [ ] 消息：未读、广播、家庭留言、业务跳转。
- [ ] 成长：成长值、能力指数、徽章、能力/天赋/兴趣轻测试。
- [ ] 团队：小组成员、岗位、研学手册、安全规则、成果提交。
- [ ] 研学日记：导入素材、生成日记、保存草稿。
- [ ] AI识物：拍照识别、解释、继续追问、回填任务。
- [ ] AI创作：AI 绘画、AI 视频、保存、分享、提交作品。
- [ ] 课程：断点续播、课程闪记、专家伴学、课后任务。
- [ ] 广场：专家智能体分类、近期使用、活动挑战。
- [ ] 聊天：微聊、群聊、图片/任务卡分享、安全边界。
- [ ] 好友：好友列表、添加好友、确认态、斗卡入口。
- [ ] 朋友圈：动态查看、发布、评论、点赞、可见范围。
- [ ] 支付：付款码、余额、消费记录、家长授权边界。
- [ ] 网盘：文件分类、搜索、预览、转发素材。
- [ ] 会议：对讲、AI 纪要、行动项、同步任务或群聊。
- [ ] 我的：个人资料、课程、报告、证书、日记、收藏、设备信息。
- [ ] SOS：组合键触发、二次确认、通知老师和家长。
- [ ] 设置：设备绑定、权限开关、系统检测、账号切换入口。

## 8. 重点交互验收

- [ ] 点击应用中心任意入口后，右侧详情卡同步切换。
- [ ] 点击“进入应用”后，进入该应用工作台。
- [ ] 点击应用操作按钮后，进度、结果卡和最近操作记录更新。
- [ ] 支付点击“付款码”后展示模拟码。
- [ ] SOS 第一次点击“长按报警”进入等待确认，第二次点击进入已模拟发送。
- [ ] 设置页的人脸识别、支付授权、定位权限开关可切换。
- [ ] 问问页展示孩子与研小宝多轮对话气泡。
- [ ] 拍拍页展示相机预览和可提交状态。
- [ ] 全应用页面的分区按钮可点击并切换提示文案。

## 9. 视觉与小屏验收

- [ ] 手表外壳、屏幕、顶部状态栏、底部语音 Dock 在桌面和移动视口均不遮挡内容。
- [ ] 应用网格文字不溢出、不重叠。
- [ ] 工作台标题、按钮、指标卡和记录列表在手表宽度内稳定。
- [ ] 关键操作按钮具备明确点击目标。
- [ ] 支付、SOS 等敏感能力有醒目的安全提示。
- [ ] 视觉风格为 AI 手表产品演示，不是传统后台或普通移动端列表。
