# 新版设备端新旧版差异对比

## 1. 对比结论

新版设备端不是在旧版 `apps/device-shell` 上改造，而是在 `apps/device-agent-shell` 中新增独立 AI Agent 手表前端演示。旧版保持原样，用于业务方并行对比和问题排查。

新版只开发完整可交互前端 mock，不开发后端和 API 接口。

## 2. 运行与隔离

| 项目 | 旧版设备端 | 新版设备端 | 验收关注点 |
| --- | --- | --- | --- |
| 应用目录 | `apps/device-shell` | `apps/device-agent-shell` | 新版变更不包含旧版目录 |
| 运行脚本 | `pnpm dev:device` | `pnpm dev:device-agent` | 双端口可同时演示 |
| 默认端口 | `3105` | `3110` | 业务方可并排打开 |
| 数据方式 | 本地存储、旧版 mock 与部分模块化数据 | 纯前端状态和预置 mock | 新版不请求 API |
| UI 技术风格 | 多路由页面、Ant Design 组件、传统应用入口 | 单页手表 shell、Agent 主屏、四屏导航 | 新版更贴近 AI 手表设备 |

## 3. 模块差异表

| 模块 | 旧版实现 | 新版实现 | 保留内容 | 主要变化 |
| --- | --- | --- | --- | --- |
| 入口页 | `/` 自动跳转 `/login` | 单页内先进入设备初始化 | 登录前置流程保留 | 新版不跳路由，保持手表壳内流程连续 |
| 设备初始化 | 租赁、销售、扫码授权，租赁码旧版为 `123456` | 租赁、销售、扫码授权，体验码为 `260323` | 三种初始化方式、设备码、错误提示 | 视觉升级为 AI 手表设备卡片 |
| 学员登录 | `/student-login` 选择账号或人脸 | 手表内选择账号或人脸 | 登录方式选择、添加账号意图 | 减少路由跳转，保留状态表达 |
| 账号登录 | Ant Design 表单、旧版 session 逻辑 | 本地账号选择、手机号、密码、错误提示 | 手机号密码登录、演示账号 | 不写 session，仅前端状态进入主屏 |
| 人脸登录 | 独立人脸登录页 | 准备、扫描、成功三状态 | 人脸登录能力 | 更适合设备端演示节奏 |
| 主屏 | 传统首页或工作区入口 | AI 智能体成长伙伴主屏 | 当前任务与快捷入口 | Agent 主动提示成为第一层体验 |
| 导航结构 | 多页面、多模块路由 | 通知、成长、Agent、应用四屏 | 应用入口保留 | 改为手表滑动空间结构 |
| 应用中心 | 旧版应用与数据模块分散 | 21 个应用统一入口、详情、工作台 | 应用清单完整保留 | 每个应用都能进入完整 mock 页面 |
| 任务 | 旧版任务数据结构完整，表单和作品类型复杂 | 小小生态公园设计师主线、任务卡、卡包、斗卡均为独立 Agent 对话页 | 任务、作品、评分、成长沉淀 | 主屏只作为入口，任务执行迁移到可逐步推进的 Agent 聊天流 |
| 拍拍 | 旧版采集和分享能力 | 相机预览、重拍、保存、转发 | 拍照采集与任务回填 | 强化实体拍照键和任务上下文 |
| 问问 | 旧版 AI 助手能力 | 上下文多轮问答、保存答案 | AI 提问入口 | 强调任务、照片、课程上下文 |
| 闪记 | 旧版语音/视频记录 | 语音闪记、视频闪记、转写、整理 | 快速记录能力 | 与实体键绑定更明确 |
| 消息 | 旧版消息数据模块 | 未读、广播、家庭、任务跳转 mock | 通知与广播 | 聚合为“现在该做什么”的通知中心 |

| 研学日记 | 旧版日记数据 | 素材导入、AI 初稿、保存草稿 | 日记生成与成长档案 | 用任务、照片、语音、评价做聚合演示 |

| 好友 | 旧版好友与社交 | 好友、添加确认、斗卡入口 | 添加好友、斗卡 | 强化确认态，不自动建立关系 |

| 设置 | 旧版设备绑定和权限 | 绑定、权限开关、系统检测 | 设备码、权限、账号切换入口 | 开关只影响前端状态 |

## 4. 新版新增的演示价值

- AI Agent 主屏成为设备默认体验，不再只是应用入口集合。
- 四屏结构更像手表设备：通知、成长、Agent 主屏、应用中心。
- 21 个应用都具备进入后的完整 mock 页面，方便业务方逐个演示。
- 支付、SOS、社交等敏感能力明确标注授权和安全边界。
- 所有 AI 能力可演示流程，但不会调用真实模型或后端接口。
- 旧版与新版可同时打开，便于业务方对比视觉、流程和功能覆盖。

## 5. 对比验收方法

1. 启动旧版：`pnpm dev:device`。
2. 启动新版：`pnpm dev:device-agent`。
3. 分别打开旧版端口 `3105` 与新版端口 `3110`。
4. 按登录、主屏、应用中心、任务、成长、社交、支付、SOS、设置逐项对比。
5. 验证新版改动文件不包含 `apps/device-shell/**`。
6. 验证新版源码不存在真实 API 请求关键词。
