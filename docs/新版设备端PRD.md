# 研学宝新版设备端 PRD

## 1. 文档信息

- 文档名称：新版设备端 PRD
- 适用范围：新版 AI Agent 手表设备端原型 `apps/device-agent-shell`
- 目标读者：原型设计、前端开发、业务评审、测试验收
- 文档定位：高保真原型演示 PRD，不作为后端正式接口联调文档
- 版本：V1.0
- 输出日期：2026-06-03

## 2. 开发隔离约束

### 2.1 分支与代码隔离

新版设备端必须在独立分支 `codex/device-agent-v2` 上开发。

代码层面采用新增 App 的方式隔离：

- 旧版设备端：`apps/device-shell`
- 新版设备端：`apps/device-agent-shell`

新版开发不得修改旧版设备端目录下的页面、组件、数据、样式和配置。旧版设备端仅作为业务能力与交互参考，不作为新版代码的改造目标。

允许修改或新增的范围：

- 新增 `apps/device-agent-shell`
- 新增或修改新版 PRD、说明文档
- 新增根脚本，例如 `pnpm dev:device-agent`
- 必要时复用 `packages/*` 下的公共类型、配置和 UI 基础能力

### 2.2 并行演示

为了方便业务方对比新旧设备端：

- 旧版设备端继续使用 `pnpm dev:device`，默认端口 `3105`
- 新版设备端使用 `pnpm dev:device-agent`，默认端口 `3110`
- 两个设备端可同时运行、同时打开、逐流程对比

验收时需确认变更文件不包含 `apps/device-shell/**`。

### 2.3 旧版功能沿用与设计升级边界

新版设备端的改版原则是“AI Agent 主线和视觉体验升级”，不是重做或删减旧版已经确认不变的业务能力。

以下模块属于旧版能力沿用范围，除 PRD 明确提出改动外，必须保留原有功能、入口、页面状态、异常提示和业务分支：

- 登录与账号：设备初始化、租赁模式、销售模式、扫码授权、授权码登录、学员账号登录、人脸登录、添加账号流、返回登录方式
- 应用中心：原有应用入口完整保留，只按新版视觉和小屏排布升级
- 我的 / 个人中心：课程、报告、证书、研学日记、收藏、账号信息、设置入口等原功能保留
- 设置：设备绑定、锁屏密码、人脸识别、支付卡授权、切换账号、设备模式展示等原功能保留
- 消息、团队、任务、成长、拍拍、问问、闪记、AI识物、AI创作、课程、广场、聊天、好友、朋友圈、支付、网盘、会议、SOS 等旧版主流程保留

设计稿与原型实现必须遵循：

- 不得因为新版视觉简化而删除旧版已有功能
- 不得把旧版已有的多状态页面改成单一展示卡片
- 不得把旧版明确存在的入口改成“说明文字”或不可操作占位
- 允许调整布局、视觉层级、图标、文案密度和控件样式
- 允许补充 Agent 提醒、AI 状态和儿童友好的表达
- 允许将旧功能重新组织成更适合手表小屏的步骤流，但功能结果必须等价

验收时需用旧版设备端作为对照：若旧版某个未变更功能可以完成，新版视觉稿和原型也必须体现对应入口与状态。

## 3. 产品定位

新版设备端定位为 AI Agent 手表设备端。

核心目标不是把旧版页面换成新视觉，而是把设备端从传统应用入口集合升级为“AI 智能体成长伙伴”：

- 看得懂当前学员、任务、团队、课程、成长值和消息状态
- 能主动提醒学员完成任务、补充作品、查看反馈
- 能调度任务、拍拍、问问、闪记、广场、成长等业务模块
- 能把照片、语音、回答、评分、日记和能力变化沉淀为成长资产

产品主张：

让孩子在真实世界里，一边看、一边拍、一边问、一边记，一边完成研学任务。

## 4. 设备与交互原则

### 4.1 设备形态

新版设备端按 AI 手表优先设计：

- 小屏触控优先
- 支持左右滑、上滑等空间导航
- 支持实体拍照键和语音键
- 支持短时间户外研学、移动中操作、低阅读负担

### 4.2 实体键约束

- 唤醒设备：进入 AI 智能体主屏
- 拍照键单击：进入拍拍
- 语音键单击或长按：进入问问
- 语音键双击：进入语音闪记
- 拍照键双击：进入视频闪记
- 拍照键 + 语音键长按：触发 SoS 报警

### 4.3 儿童安全边界

原型演示可以完整展示支付、好友、聊天、朋友圈等旧版能力，但必须标注授权边界：

- 支付需家长授权
- 加好友需双方确认，可配置家长授权
- 朋友圈发布需展示可见范围、审核或授权状态
- SoS 为高优先级安全能力，入口和组合键均需明确

## 5. 一级信息架构

新版设备端采用“四屏”结构。

### 5.1 主屏：AI 智能体成长伙伴

设备唤醒后的默认页面。

主要内容：

- 顶部状态：消息提醒、任务提醒、网络、电量
- 中心：AI 智能体成长伙伴形象与主动提示
- 任务上下文：当前活动、当前步骤、任务进度、成长值反馈
- 快捷入口：任务、拍拍、问问、闪记、广场
- 输入能力：语音输入、文字输入

Agent 人设为成长伙伴、探索队长、成长搭子。语言应短、明确、鼓励式，不像传统系统提示。

### 5.2 上一屏：通知中心

主屏上滑进入。

聚合内容：

- 任务提醒
- 团队广播
- 小组消息
- 聊天提醒
- 家庭留言
- 系统通知
- 订阅消息

通知中心解决“现在有什么待处理”的问题。每条通知需支持跳转到对应任务、消息、团队、课程或广场内容。

### 5.3 左一屏：成长中心

主屏左滑进入。

主要内容：

- 当前成长值
- 能力指数 / 能力雷达
- 最近成长记录
- 当前团队与小组信息
- 成长画像完成度
- 能力、天赋、兴趣入口

成长中心解决“我最近成长了什么、还差什么”的问题。

### 5.4 右一屏：应用中心

主屏右滑进入。

应用中心按新版原型图完整保留以下入口：

- 任务
- 拍拍
- 问问
- 闪记
- 消息
- 成长
- 团队
- 研学日记
- AI识物
- AI创作
- 课程
- 广场
- 聊天
- 好友
- 朋友圈
- 支付
- 网盘
- 会议
- 我的
- SOS
- 设置

应用中心名称统一为“应用中心”。团队入口名称使用“团队”。

### 5.5 登录与账号模块

登录模块属于旧版沿用模块。新版只做视觉升级和 AI 手表小屏适配，不改变旧版登录业务能力。

登录模块必须保留以下页面与状态。

#### A. 设备初始化绑定

保留旧版能力：

- 展示设备码
- 展示当前初始化方式
- 支持租赁模式
- 支持销售模式
- 支持扫码授权
- 租赁模式输入六位设备授权码
- 授权码输入限制为数字与 6 位长度
- 授权码错误时给出错误提示
- 销售模式说明无需授权码，完成初始化后进入学员登录
- 扫码授权展示二维码或扫码授权状态
- 初始化完成后进入学员登录

新版设计要求：

- 视觉上可升级为 AI 手表设备卡片
- 三种初始化方式必须仍是明确可切换控件
- 设备码、模式状态、授权码输入框和确认按钮不得删除

#### B. 学员登录方式选择

保留旧版能力：

- 展示设备状态：已初始化
- 展示学员账号状态：待登录或添加新账号
- 支持账号登陆
- 支持人脸登陆
- 支持添加账号流 `intent=add-account`
- 提示学员账号注册不在设备端进行，需使用已分配账号登录

新版设计要求：

- 账号登陆与人脸登陆必须是两个明确主入口
- 添加账号流与普通登录流在文案上需要区分
- 不得把学员登录方式选择合并为单个“登录”按钮

#### C. 账号登陆

保留旧版能力：

- 手机号输入
- 密码输入
- 演示密码提示
- 演示账号列表快速填充
- 登录成功进入主屏
- 添加账号流下按钮文案为“添加并登录账号”
- 支持返回登录方式
- 手机号或密码错误时提示错误

新版设计要求：

- 手机号、密码、演示账号、主按钮、返回按钮都必须保留
- 允许将演示账号改为更适合小屏的账号卡片或横向选择

#### D. 人脸登陆

保留旧版能力：

- 展示等待识别、正在识别、识别成功三种状态
- 点击开始识别
- 识别成功后进入主屏
- 添加账号流下识别成功后新增账号并进入主屏
- 展示学员身份校验与前端模拟识别标签
- 支持返回登录方式

新版设计要求：

- 识别状态、开始识别按钮、返回登录方式不得删除
- 可增加摄像头取景框、识别动画和 Agent 友好提示

## 6. Agent 能力边界

新版 Agent 为业务编排型 Agent。

### 6.1 上下文感知

Agent 需要理解当前上下文：

- 学员身份
- 当前任务
- 当前团队和小组
- 当前页面
- 输入来源
- 消息状态
- 成长值和能力指数
- 课程进度
- 设备状态

### 6.2 意图识别

Agent 需要识别学员意图：

- 问问题
- 查任务
- 拍照
- 提交作品
- 记录闪记
- 查看成长
- 找智能体
- 生成研学日记
- 发起斗卡

### 6.3 功能调度

Agent 可调度以下模块：

- 任务
- 拍拍
- 问问
- 闪记
- AI识物
- AI创作
- 成长
- 广场
- 课程
- 研学日记

原型阶段调度可使用 Mock 数据和预置结果模拟。

### 6.4 业务流程编排

Agent 不只回答问题，还要推进业务流程：

- 研学前准备
- 任务触达
- 任务执行
- AI 校验
- 待补充提醒
- 任务完成
- 成长值结算
- 能力画像更新
- 研学日记生成

### 6.5 数据沉淀

需要沉淀为后续成长分析的数据：

- 问答记录
- 任务作品
- 照片和语音
- 闪记
- 课程学习记录
- 斗卡记录
- 成长值记录
- 能力、天赋、兴趣结果
- 研学日记

## 7. 演示主线

首版原型演示采用“小小生态公园设计师”案例。

### 7.0 主线 Agent 对话页

主屏中的“主线”入口只负责进入主线，不在主屏内直接执行任务卡。点击后打开独立 AI Agent 主线对话页：

- 保留手表状态栏，隐藏四屏 Tab，顶部提供返回主屏按钮
- 页面主体为 Agent 与学员的聊天流，每次点击当前操作按钮后追加下一段 mock 消息
- 不自动连续刷完任务，必须由学员逐步点击推进
- 对话页覆盖 22 个 mock 节点：研学前准备、任务一、任务二、任务三、活动总结、成长奖励、研学日记保存
- 当前步骤可展示任务卡式消息、进度、模拟照片/插图、锦囊、设计图、报告摘要、能力雷达和日记素材
- 返回主屏后保留主线进度，完成奖励后同步更新主屏和成长中心的成长值

### 7.0.1 全模块 Agent 独立页

新版主屏不再承载卡包、斗卡、画像、日记等模块的执行内容。主屏只展示入口和进度摘要，点击后进入独立 Agent 对话页。

首版需要完成以下独立 Agent 页：

- 任务卡 Agent：任务触达、选项问答、拍照校验、语音转写、关键信息确认、关系问答、AI 反馈和综合结算
- 卡包 Agent：任务卡包筛选、我的卡包、卡片统计、系列图鉴
- 斗卡 Agent：邀请、超时/应战、规则、准备房间、同步答题、结算、排行榜
- 能力 Agent：3 道情境题、能力雷达、成长建议
- 天赋 Agent：情境问答、行为偏好、潜力方向、智能体推荐
- 兴趣 Agent：兴趣选择、拍摄/提问依据、标签确认、任务推荐
- 画像 Agent：聚合能力、天赋、兴趣和任务表现，生成成长画像
- 日记 Agent：素材清单、AI 初稿、补充感受、保存日记

以上页面均使用和主线一致的聊天流：状态栏、返回按钮、阶段进度、成长值、Agent 气泡、学生回复、当前操作按钮和专属 widget。每次点击只推进一个 mock 节点。

### 7.1 研学前准备

触发条件：

- 学校或研学团队已创建活动
- 已完成分组、安全告知和任务发放
- 学员打开设备或进入待机提醒

Agent 提醒内容：

- 活动名称
- 活动地点
- 学员身份
- 核心任务
- 安全提醒
- 小组信息
- KWL 表 K/W 部分

### 7.2 任务一：探访野朋友

任务目标：

- 观察公园里的动物和植物
- 拍摄照片
- 说出观察
- 记录名称、数量、地点和时间
- 提出一个和生态环境相关的问题

设备端流程：

1. Agent 在主线对话页推送任务卡式消息
2. 学员选择观察对象：动物 / 植物 / 不确定
3. 学员拍照
4. AI 模拟识别照片是否符合任务
5. 学员语音描述观察
6. 系统模拟语音转文字
7. 学员补充关键信息
8. Agent 给出成长值和能力反馈
9. 任务卡完成

### 7.3 任务二：生态设施大搜索

任务目标：

- 按顺序完成 10 个锦囊挑战
- 找到生态设施
- 拍摄设施照片
- 说明设施作用
- 完成后解锁下一个锦囊

原型要求：

- 展示锦囊顺序锁定
- 展示 AI 校验通过和驳回重拍状态
- 展示每个锦囊的成长值反馈
- 支持任务完成进度

### 7.4 任务三：生态设施创想

任务目标：

- 小组合作设计一个生态设施
- 明确设施名称、目标物种、预期作用和设计图

设备端流程：

1. Agent 引导小组讨论
2. 学员可先语音说想法
3. 学员可拍摄草图
4. AI创作可辅助生成设计图
5. 小组提交设计方案
6. Agent 沉淀组员贡献

### 7.5 活动总结与评价

活动完成后，Agent 引导学员完成：

- KWL 表 L：我学到的
- 我的收获
- 我还想了解
- 小组自评
- 同学互评

老师和专家评价由后续系统生成，原型阶段可用预置内容展示。

### 7.6 成长值与研学日记

老师评价和研学报告生成后，设备端展示：

- 本次成长值奖励
- 最新能力雷达变化
- 研学报告入口
- 生成研学日记入口

研学日记由 Agent 整理以下素材生成：

- 任务作品
- 观察照片
- 语音记录
- 小组设计方案
- 老师评价
- 研学报告摘要
- 成长值和能力雷达变化

## 8. 任务卡与卡包

### 8.1 任务卡触达

任务卡触达来源：

- 老师下发
- 家长下发
- 专家下发
- LBS 位置推荐
- Agent 根据成长画像推荐

任务卡展示内容：

- 任务名称
- 培养重点
- 预计耗时
- 可获得成长值
- 推荐原因
- 开始任务按钮

### 8.2 任务执行

任务执行页采用一步一引导形式：

- 当前步骤
- 当前题目或要求
- 可用工具
- 已采集内容
- AI 校验结果
- 成长值反馈
- 下一步按钮

任务卡片执行必须按原型图采用问答式任务链路，而不是静态任务大卡片。以“任务一：探访野朋友”为示例：

1. Step 1/6 选择观察对象：Agent 提问“你这次想观察的是哪一类野朋友？”，学员选择动物、植物或不确定。
2. Step 1/6 选择反馈：Agent 确认已选择观察对象，提示下一步拍照，并发放基础成长值。
3. Step 2/6 拍照提交：展示模拟照片、AI 检查状态、拍照、从相册选择、重新拍摄和提交本题。
4. Step 2/6 驳回重拍：当照片不符合任务要求时，Agent 提示“这看起来不像我们要找的野朋友”，要求重新拍摄。
5. Step 2/6 校验通过：照片符合任务要求后，展示识别成功和成长值反馈。
6. Step 3/6 语音描述：展示照片缩略图、录音按钮、录音时长、语音转文字结果，支持重新录音和接受回答。
7. Step 4/6 关键信息确认：展示物种名称、数量、地点、时间和语音转写，可查看或修改后提交。
8. Step 5/6 关系问答：Agent 提问“它和周围环境有什么关系？”，学员通过语音或文字回答。
9. Step 6/6 AI 小助手总结：展示观察成果、成长值、能力维度变化，并进入任务完成页。

可用工具包括：

- 拍拍
- 问问
- 闪记
- AI识物
- AI创作
- 语音转文字

### 8.3 任务完成

任务完成页展示：

- 综合评分
- 成长值奖励
- 能力维度变化
- 任务作品摘要
- 是否点亮任务卡
- 生成研学日记入口
- 发起斗卡入口

### 8.4 我的卡包

我的卡包展示：

- 累计获得卡片
- A+ 高分卡
- 完成任务次数
- 斗卡胜利次数
- 最近获得卡片
- 系列卡收集进度
- 未点亮卡片占位

## 9. 斗卡

斗卡按《研学宝全新版设备端原型设计方案》4.3 原型实现，首版采用本地模拟实时 PK，不接真实实时通信。

### 9.1 4.3.1 斗卡邀请

触发条件：

- 学员完成某个通用任务
- 学员从任务完成页或好友页发起斗卡
- 好友向学员发起斗卡邀请

邀请页展示：

- 小宇向学员发起“任务一：探访野朋友”斗卡邀请
- 发起人头像、评级、成长值、累计卡片数
- 斗卡说明：完成同一套 6 个问题后计算综合 PK 分
- 任务预览：选择观察对象、拍下野朋友、说出观察、确认信息、生态关系、完成结算
- 操作：接受斗卡、稍后

### 9.2 4.3.2 斗卡规则

斗卡评分维度：

- 基础有效分：内容是否符合题意
- 速度分：在保证质量前提下完成越快得分越高
- 创意分：想法是否新颖具体
- 进步分：相比历史表现是否进步

规则页展示：

- 单题得分 = 基础有效分 + 速度分 + 创意分 + 进步分
- 任务 PK 总分 = 各题得分累计 + 完成奖励分
- 单选题、拍照题、语音/思考题的评分差异
- 操作：开始斗卡

### 9.3 4.3.3 斗卡流程

斗卡流程使用预置好友“小宇”作为模拟对手，但必须按真实答题节奏推进：

1. 进入斗卡后先展示题目，不提前展示本题结果。
2. 学员先完成答题动作，系统再模拟填充回答内容，然后才进入当前题结果、AI 反馈和本题分项得分。
3. 单题结果页只展示当前题，不展示后续题目或最终总分。
4. 顶部持续展示双方累计分、当前进度和综合 PK 分说明。
5. 完成 6 道题后才进入斗卡完成页。

6 道题固定为：

- Step 1：选择观察对象，选项为动物、植物、不确定。
- Step 2：拍下野朋友，先显示“拍照 / 从相册选择”，完成后再出现“重新拍摄 / 从相册选择 / 提交照片”或“拍照 / 重新选择 / 提交照片”。
- Step 3：语音描述，先显示“录音”，录完后再出现“重新录音 / 提交录音”。
- Step 4：确认关键信息，先显示待整理状态，整理完成后再出现“修改 / 提交本题”。
- Step 5：生态关系问答，先显示“语音回答 / 文字输入”，输入完成后再出现“重新语音 / 提交回答”或“重新输入 / 提交回答”。
- Step 6：提交任务卡，先显示待整理状态，整理完成后再出现“重新整理 / 提交任务卡”。

累计比分按本地 mock 推进：初始 0 vs 0；Step 1 后 10 vs 9；Step 2 后 22 vs 24；Step 3 后 38 vs 42；Step 4 后 56 vs 58；Step 5 后 74 vs 72；Step 6 后 92 vs 88。

### 9.4 4.3.4 斗卡完成

结算页展示：

- 斗卡完成和胜负结果：你赢了
- 任务完成状态：任务一“探访野朋友”6/6 步完成
- 双方总分：学员 92 分，小宇 88 分
- 双方评级和成长值奖励：学员 A、+50 成长值；小宇 A、+35 成长值
- 五项分项表现对比：基础有效分、速度分、创意分、进步分、完成奖励分
- 排行榜摘要：参与人数 8 人，当前排名第 2 名
- 操作：再挑战一次、邀请其他好友、查看完成态任务卡、返回任务卡组

### 9.5 4.3.5 斗卡排名

排行榜展示：

- 任务卡信息：任务一“探访野朋友”
- 能力标签：观察力、表达力、科学思维
- 参与人数：8 人
- 我的排名：第 2 名
- 我的综合 PK 分、评级、成长值和五项分项得分
- 8 人排行榜：名次、昵称、综合 PK 分、评级、累计成长值、累计卡片数
- 操作：再挑战一次、邀请好友、查看我的累计卡片、返回任务主相

不展示：

- 非原型主流程里的单独超时页
- 非原型主流程里的准备房间页
- “mock / 演示 / 点击展示”等非业务说明

## 10. 天赋、兴趣与能力

该模块在原型中做完整轻测试，不做深度题库系统。

### 10.1 功能入口

入口包括：

- 主屏 Agent 主动推荐
- 成长中心入口
- 应用中心“成长”
- 任务完成后推荐补充画像

### 10.2 能力测试

能力测试通过语音、文字或选择题引导学员完成。

原型要求：

- 展示 3 分钟轻测试
- 展示题目或情境问题
- 展示完成进度
- 每道题必须先选择或录入答案，再生成“我的回答”草稿
- 提交前不得展示能力雷达、评分结果或成长建议
- 完成后生成能力雷达和成长建议

问答化流程：

1. 展示题目和选项
2. 学员点击选项后，前端本地模拟填充回答
3. 页面展示“重新选择”和“提交本题”
4. 点击提交后进入下一题
5. 3 道题全部提交后生成能力雷达

### 10.3 天赋测试

天赋测试通过情境问答帮助学员发现优势方向。

原型要求：

- 展示天赋探索引导
- 展示 3-5 个情境问题
- 情境题必须先选择方向或整理任务表现，再提交
- 提交前不得提前展示潜力方向和推荐智能体
- 展示潜力方向
- 展示对应推荐任务

问答化流程：

1. 情境题先展示可选方向
2. 学员选择 1-2 个方向后生成“我的回答”
3. 行为偏好题先点击“整理任务表现”或“手动补充”
4. 填充完成后才能提交并生成潜力方向

### 10.4 兴趣爱好

兴趣爱好用于推荐任务和智能体。

原型要求：

- 支持主动选择兴趣标签
- 支持 Agent 根据近期拍摄和提问模拟兴趣确认
- 支持在推荐确认阶段添加、忽略、稍后再说
- 兴趣标签必须先由学员选择或确认后再写入结果
- 推荐确认阶段的“忽略”和“稍后再说”只保留当前状态，不推进成长画像完成度

问答化流程：

1. 学员先主动选择兴趣标签
2. 前端本地模拟填充“我的兴趣”
3. Agent 再展示近期拍摄和提问依据，让学员确认或忽略推荐标签
4. 确认提交后才展示最终兴趣标签和推荐任务

### 10.5 成长画像

成长画像聚合展示：

- 能力雷达
- 天赋方向
- 兴趣标签
- 成长画像完成度
- 推荐任务
- 推荐智能体

成长画像完成度只根据已提交完成的能力、天赋、兴趣流程更新。推荐确认阶段仅点击“稍后再说”或“忽略推荐”不得计入对应标签确认。

## 11. 应用中心主流程

旧版应用能力沿用，但新版需要重写为 AI 手表体验。这里的“重写”只指视觉层级、小屏布局、控件样式和 Agent 提醒方式升级，不代表删减功能。以下每个模块都必须先对照旧版功能清单，再输出新版视觉稿和原型。

应用中心相关设计稿必须同时体现：

- 旧版保留功能：旧版已有且本 PRD 未明确取消的功能
- 新版视觉升级：更适合 AI 手表的布局、图标、卡片、状态和动效表达
- Agent 辅助能力：只作为增强提示和业务编排，不替代旧版原功能入口

### 11.1 任务

- 展示任务卡列表
- 支持全部、已完成、待补充、斗卡挑战
- 可进入任务执行页
- 可查看任务完成结果
- 可进入卡包和斗卡

### 11.2 拍拍

- 拍照键进入
- 支持拍照、重拍、裁剪、保存
- 拍照后可转发到任务、AI识物、问问、研学日记
- 若来自任务上下文，优先回填当前任务

### 11.3 问问

- 保留“问问”名称
- 支持语音和文字输入
- 支持当前任务、课程、照片上下文
- 支持回答采纳为任务作品或过程证据
- 专家伴学作为广场或课程内的子能力

### 11.4 闪记

- 语音闪记：录音、转写、补拍 1-9 张照片
- 视频闪记：录制视频并保存
- 闪记可关联任务、课程和研学日记
- 任务内新建闪记后需回流当前题目

### 11.5 消息

- 聚合团队广播、小组广播、点对点、系统、家庭和订阅消息
- 高优先级语音广播自动播报一次
- 未读数量在顶部、通知中心和应用中心同步展示
- 消息详情支持跳转业务对象

### 11.6 成长

- 展示能力指数
- 展示成长值、明细和规则
- 展示能力、天赋、兴趣入口
- 展示成长画像和最近成长记录

### 11.7 团队

- 查看当前团队
- 支持扫码入团和碰一碰入团演示
- 查看小组、岗位、队名、队徽
- 查看研学手册、团队任务、排行、报告和证书
- 小组组长可维护名称、徽章和岗位

### 11.8 研学日记

- 展示日记列表
- 支持选择素材生成日记
- 支持 AI 初稿、补充要求、重新生成和保存
- 支持从任务完成页直接生成

### 11.9 AI识物

- 支持拍照识别
- 支持结果语音播报和文字展示
- 支持基于照片继续追问
- 支持结果回填任务

### 11.10 AI创作

AI创作统一包含：

- AI绘画
- AI视频

主流程：

1. 选择底图、模板或任务素材
2. 输入或语音说出提示词
3. 生成图片或视频
4. 保存到本地素材
5. 可提交任务、分享或写入日记

### 11.11 课程

- 展示课程列表
- 支持断点续播
- 支持课程目录
- 支持课程闪记
- 支持进入专家伴学

### 11.12 广场

- 定位为专家智能体广场
- 展示分类、智能体列表、近期使用
- 支持添加到主屏
- 智能体详情包含专家介绍、课程、资讯和挑战

### 11.13 聊天

- 聚合微聊和群聊
- 支持文字、语音、图片和任务卡分享
- 支持从斗卡邀请进入好友对战
- 需展示授权边界

### 11.14 好友

- 展示好友列表
- 支持研学宝 ID、手机号和碰一碰加好友演示
- 支持确认好友申请
- 支持发起微聊、电话、对讲和斗卡

### 11.15 朋友圈

- 查看动态
- 点赞、收藏、评论、转发
- 从相册、任务作品或日记选择素材发布
- 发布前展示可见范围和审核状态

### 11.16 支付

- 展示家长授权亲子卡
- 支持付款码、余额、消费记录
- 原型不接真实支付
- 明确家长授权边界

### 11.17 网盘

- 展示文件分类
- 支持视频、音频、图片、电子书、PDF 预览
- 文件可加入任务、日记或分享

### 11.18 会议

- 支持创建会议
- 支持长按语音键对讲
- 支持生成 AI 纪要
- 纪要可分享给群聊或加入任务

### 11.19 我的

- 展示学员头像、研学宝 ID、账号信息
- 展示我的课程、报告、证书、日记、收藏
- 支持进入设置和切换账号

### 11.20 SOS

- 支持应用中心红色入口
- 支持拍照键 + 语音键长按
- 展示倒计时、取消和发送成功状态
- 报警信息包含 GPS 位置、录音和文字说明

### 11.21 设置

- 设备绑定
- 锁屏密码
- 人脸识别
- 支付卡授权
- 切换账号
- 租赁 / 销售模式展示

## 12. 原型数据与 AI 模拟

首版原型使用 Mock 数据模拟 AI 能力。

可模拟的 AI 表现：

- 照片识别是否符合任务

- 问问回答
- 任务评分
- 成长值计算
- 斗卡对手答题
- 研学日记生成
- 兴趣标签推荐
